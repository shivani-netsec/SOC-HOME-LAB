# Wazuh Integration

## Environment

Ubuntu Server 22.04

Windows 10

Kali Linux

Oracle VirtualBox

## Steps Completed

1. Installed Wazuh on Ubuntu Server.
2. Accessed the Wazuh Dashboard through a web browser.
3. Deployed the Wazuh Agent to the Windows 10 VM.
4. Registered the Windows endpoint with the Wazuh server.
5. Confirmed the agent status as Active.
6. Verified that Windows security events are being collected.
